# Vite + React (SPA)

This UI is a **Vite** single-page app with **React Router**. Use `npm run dev` / `npm run build` / `npm run preview`. Client env vars must be prefixed with `VITE_` (see `src/lib/env.ts`). For GitHub Pages under a project path (not a custom domain at `/`), set `base` in `vite.config.ts` to match the repo subpath.
